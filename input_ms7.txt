# MS7 demo: FCFS vs SJF
#
# Timing designed so T1 and T2 BOTH arrive at hub node 3
# while T0 is still inside it (all three queue up together):
#
#   T0: source edge w1 -> arrives hub at t=1.3s, leaves at t=2.3s
#   T1: source edge w4 -> arrives hub at t=2.2s  (inside T0's stay) QUEUED
#   T2: source edge w4 -> arrives hub at t=2.2s  (inside T0's stay) QUEUED
#
# When T0 leaves at t=2.3s, both T1 and T2 are waiting:
#
#   T1 (blue)   : next edge 3->5  weight 20  (heavy - slow exit)
#   T2 (purple) : next edge 3->6  weight  1  (light - fast exit)
#
# FCFS: T0 -> T1 -> T2  (T1 was first in queue since i=1 read before i=2)
# SJF:  T0 -> T2 -> T1  (T2 has lighter next edge weight, goes before T1)
#
# Clear visible difference: BLUE goes 2nd in FCFS, LAST in SJF
